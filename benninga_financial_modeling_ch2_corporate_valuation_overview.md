## Chapter 2: Corporate Valuation Overview (Enterprise Value, Equity Value, DCF vs Multiples vs Book Value, Free Cash Flow)

### Core Concept
Corporate valuation is the process of estimating a company’s **enterprise value (EV)** (value of operating assets) and then translating that into **equity value** (value attributable to shareholders) after adjusting for financing and non-operating items. This chapter frames three common valuation “anchors” (book value, market/efficient markets, and discounted cash flow) and introduces **free cash flow (FCF)** as the cash-based foundation for intrinsic value.

### Formula/Methodology
```text
Enterprise Value (EV) = Value of operating assets (productive activities)

Equity Value = EV - Net Debt - Other senior claims + Non-operating assets
Where:
Net Debt = Interest-bearing debt - Excess cash (cash not needed for operations)
Other senior claims = preferred equity, minority interests, pension deficits (case-dependent)
Non-operating assets = investments, surplus real estate, cash beyond operating needs
```

```text
Core intrinsic value idea (DCF):
EV = Present Value of expected future Free Cash Flows (FCF) discounted at the cost of capital (WACC)

EV = Σ_{t=1..N} [ FCF_t / (1 + WACC)^t ] + TV_N / (1 + WACC)^N
Where:
FCF_t = Free cash flow in year t
WACC = Weighted average cost of capital (decimal, e.g., 0.09 for 9%)
TV_N = Terminal value at forecast horizon N (handled in continuing value chapters)
```

```text
Free Cash Flow (operating definition used for EV):
FCF = NOPAT + D&A - Capex - ΔNWC
Where:
NOPAT = EBIT × (1 - Tax rate)  (operating profit after tax)
D&A = Depreciation & amortisation (non-cash)
Capex = Capital expenditure required to sustain/grow operations
ΔNWC = Change in net working capital (operating current assets - operating current liabilities)
```

```text
Free Cash Flow from cash flow statement (common shortcut):
FCF ≈ Cash Flow from Operations (CFO) - Capex
Where:
CFO = cash generated by operations (after working capital and taxes, per statement)
Capex = cash paid for property, plant and equipment (and sometimes intangibles)
Note:
This shortcut is practical but must be aligned to "operating" vs "financing" classification.
```

### Python Implementation
```python
from typing import Dict, Optional

def safe_div(numerator: float, denominator: float, *, context: str = "") -> float:
    """Safely divide with clear errors to prevent silent valuation bugs."""
    if denominator == 0:
        raise ValueError(f"Division by zero{(' in ' + context) if context else ''}.")
    return numerator / denominator

def fcf_from_nopat(
    ebit: float,
    tax_rate: float,
    da: float,
    capex: float,
    delta_nwc: float
) -> float:
    """
    Compute Free Cash Flow (FCF) from operating drivers.

    Args:
        ebit: Earnings before interest and taxes for the period.
        tax_rate: Effective operating tax rate as decimal (0 to 1).
        da: Depreciation & amortisation for the period.
        capex: Capital expenditures for the period (cash basis, positive number).
        delta_nwc: Change in net working capital (increase is cash outflow; positive reduces FCF).

    Returns:
        float: Free cash flow.

    Raises:
        ValueError: If tax_rate is outside [0,1] or if any inputs are NaN.
    """
    for name, x in [("ebit", ebit), ("tax_rate", tax_rate), ("da", da), ("capex", capex), ("delta_nwc", delta_nwc)]:
        if x is None or (isinstance(x, float) and (x != x)):  # NaN check
            raise ValueError(f"{name} is missing/NaN.")
    if tax_rate < 0 or tax_rate > 1:
        raise ValueError("tax_rate must be between 0 and 1.")
    nopat = ebit * (1 - tax_rate)
    return nopat + da - capex - delta_nwc

def fcf_from_cash_flow_statement(cfo: float, capex_cash: float) -> float:
    """
    Approximate FCF using a cash flow statement shortcut.

    Args:
        cfo: Cash flow from operations (from statement).
        capex_cash: Cash capex (often 'purchase of PP&E' and sometimes intangibles).

    Returns:
        float: Approximate free cash flow.

    Raises:
        ValueError: If inputs are missing/NaN.
    """
    for name, x in [("cfo", cfo), ("capex_cash", capex_cash)]:
        if x is None or (isinstance(x, float) and (x != x)):
            raise ValueError(f"{name} is missing/NaN.")
    return cfo - capex_cash

def dcf_enterprise_value(
    fcfs: Dict[int, float],
    wacc: float,
    terminal_value: Optional[float] = None,
    terminal_year: Optional[int] = None
) -> float:
    """
    Discount a set of forecast FCFs to compute enterprise value.

    Args:
        fcfs: Mapping year_index -> FCF (e.g., {1: 100, 2: 120, ...}).
        wacc: Discount rate as decimal (must be > -1).
        terminal_value: Optional terminal value at terminal_year (undiscounted at that year).
        terminal_year: Year index where terminal_value is measured (must exist if terminal_value given).

    Returns:
        float: Enterprise value.

    Raises:
        ValueError: For invalid wacc, empty cash flows, missing terminal_year, or non-integer keys.
    """
    if not fcfs:
        raise ValueError("fcfs cannot be empty.")
    if wacc <= -1:
        raise ValueError("wacc must be greater than -1.")
    for k in fcfs.keys():
        if not isinstance(k, int) or k <= 0:
            raise ValueError("fcfs keys must be positive integers representing year indices.")
    ev = 0.0
    for t, f in sorted(fcfs.items()):
        ev += f / ((1 + wacc) ** t)
    if terminal_value is not None:
        if terminal_year is None:
            raise ValueError("terminal_year is required when terminal_value is provided.")
        if terminal_year <= 0:
            raise ValueError("terminal_year must be a positive integer.")
        ev += terminal_value / ((1 + wacc) ** terminal_year)
    return ev

def equity_value_from_enterprise_value(
    enterprise_value: float,
    debt: float,
    cash_and_investments: float,
    other_senior_claims: float = 0.0,
    non_operating_assets: float = 0.0
) -> float:
    """
    Bridge from EV to equity value using a simplified capital structure adjustment.

    Args:
        enterprise_value: Value of operating assets.
        debt: Interest-bearing debt (gross).
        cash_and_investments: Cash and marketable securities (assess operating vs excess).
        other_senior_claims: Preferred equity, minorities, pension deficits, etc.
        non_operating_assets: Non-operating assets not captured in EV.

    Returns:
        float: Equity value.

    Raises:
        ValueError: If enterprise_value is missing/NaN.
    """
    if enterprise_value is None or (isinstance(enterprise_value, float) and (enterprise_value != enterprise_value)):
        raise ValueError("enterprise_value is missing/NaN.")
    net_debt = debt - cash_and_investments
    return enterprise_value - net_debt - other_senior_claims + non_operating_assets

# Example usage (illustrative)
forecast_fcfs = {1: 120.0, 2: 140.0, 3: 160.0, 4: 180.0, 5: 200.0}
wacc = 0.09
# Terminal value would usually be computed using a continuing value method; placeholder here:
terminal_value = 2500.0
ev = dcf_enterprise_value(forecast_fcfs, wacc, terminal_value=terminal_value, terminal_year=5)
eq = equity_value_from_enterprise_value(ev, debt=600.0, cash_and_investments=150.0)
print(f"Enterprise Value (EV): ${ev:,.0f}")
print(f"Equity Value: ${eq:,.0f}")
```

### Valuation Impact
Why this matters:
- **Method selection drives the narrative**: book value, market price, and DCF can diverge materially; the analyst must explain why (growth, risk, reinvestment needs, accounting distortions, or market mispricing).
- **EV vs Equity clarity prevents category errors**: multiples such as **EV/EBITDA** require EV; **P/E** requires equity value. Mixing them produces incorrect conclusions.
- **FCF discipline improves comparability**: earnings can be affected by accounting policy choices; FCF anchors valuation in cash that can be distributed (after sustaining investments).

Impact on multiples (EV/EBITDA, P/E, etc.):
- EV-based multiples work best when you have a clean bridge from operating earnings to operating asset value.
- Equity multiples require consistent treatment of leverage, share count, and non-operating items.

Impact on DCF inputs (WACC, FCF, growth rate):
- FCF definition (NOPAT-based vs CFO-based) influences level and timing of cash flows and therefore EV.
- If the forecast period relies heavily on accounting earnings without reconciling to cash, DCF outputs become fragile.

Comparability issues across companies:
- Different capex policies (expensing vs capitalising), working capital intensity, or lease structures can change accounting earnings while leaving cash economics similar.
- Conglomerates and firms with large non-operating assets require careful EV-to-equity bridges.

Practical adjustments:
```python
def normalize_for_non_operating_items(reported_metric: float, non_operating_component: float) -> float:
    """Remove non-operating components from a reported metric to improve comparability."""
    if reported_metric is None:
        raise ValueError("reported_metric is required.")
    return reported_metric - non_operating_component
```

### Quality of Earnings Flags
⚠️ Red flag: **High earnings, weak/negative operating cash flow** for multiple periods (potential working capital build, aggressive revenue recognition, or capitalised costs).  
⚠️ Red flag: **Large “one-off” add-backs** recurring each year (suggests structural costs rather than exceptional items).  
⚠️ Red flag: **Capex materially below depreciation** for an asset-heavy business without a clear explanation (may be underinvesting; short-term FCF inflated).  
✅ Green flag: **Stable conversion** from EBIT/NOPAT to cash over time with a coherent capex + working capital story.

### Sector-Specific Considerations
| Sector | Key Issue | Typical Treatment |
|---|---|---|
| Technology / SaaS | Working capital often low; major “investment” may be in opex (R&D, sales) | Focus on unit economics and reinvestment needs; avoid assuming low capex implies low reinvestment |
| Retail / Distribution | Working capital swings can dominate CFO | Model inventory and payables explicitly; use multi-year averages for working capital intensity |
| Industrials | Sustaining capex vs growth capex split matters | Separate maintenance capex (to sustain) from expansion capex (to grow) where disclosures allow |
| Financials | Debt is operating (not a financing choice) | EV framework often inappropriate; shift to equity valuation frameworks (P/B, ROE-based) |

### Real-World Example
Scenario: A manufacturer has stable margins but volatile working capital due to inventory cycles. You want EV using a NOPAT-based FCF to control for working capital assumptions.

```python
company = {
    "ebit": 250.0,
    "tax_rate": 0.25,
    "da": 80.0,
    "capex": 110.0,
    "delta_nwc": 40.0  # inventory build consumes cash
}

fcf = fcf_from_nopat(
    ebit=company["ebit"],
    tax_rate=company["tax_rate"],
    da=company["da"],
    capex=company["capex"],
    delta_nwc=company["delta_nwc"]
)

fcfs = {1: fcf, 2: fcf * 1.03, 3: fcf * 1.03, 4: fcf * 1.03, 5: fcf * 1.03}
ev = dcf_enterprise_value(fcfs, wacc=0.10, terminal_value=1800.0, terminal_year=5)

equity = equity_value_from_enterprise_value(
    enterprise_value=ev,
    debt=900.0,
    cash_and_investments=120.0,
    other_senior_claims=50.0
)

print(f"FCF (Year 1): ${fcf:,.0f}")
print(f"Enterprise Value: ${ev:,.0f}")
print(f"Equity Value: ${equity:,.0f}")
```

Interpretation: Even with strong EBIT, a working capital build lowers near-term FCF and therefore EV. If working capital is cyclical, consider normalising ΔNWC (e.g., multi-year average) to avoid over-penalising a temporary inventory cycle.
